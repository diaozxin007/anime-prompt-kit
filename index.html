USE IT IN YOUR PROJECT

Small tools. No dependencies.

JavaScript / Node.js 20+

Clone the repository, then import the composer.

import { fromTemplate } from './index.js';

const prompt = fromTemplate('sky-courier', {
  setting: 'a snowy train station',
});

The browser uses the same JavaScript composition function. Empty fields are omitted, and fields keep a stable order.

Python 3.9+

pip install anime-prompt-kit
anime-prompt-kit --list
anime-prompt-kit sky-courier

Also available as a Python API. View the package on PyPI ↗

How the fields work

Subject → outfit → action → setting → style → lighting → composition. Choose a template to load its fields; edits update the prompt immediately. Reset restores the selected template.

The template collection contains original concepts you can edit and reuse under the MIT license.
